# Auris Hangstúdió — Színészdosszié & Portfólió

Az Auris Audio Engine 46 fős aktív színészgárdájának interaktív online casting portfóliója, akusztikai profiljai és Gemma 4 által megálmodott Krea-2 Turbo műtermi arcképei.

## Tartalom
- `index.html`: Teljes interaktív webes dashboard (keresővel, korcsoport-szűrőkkel, lightbox képnagyítással és beépített audio lejátszóval).
- `*.webp`: 46 darab 3:4 arányú műtermi színészportré (60% WebP).
- `*.wav`: 47 darab 24 kHz 16-bit mono mesterhang referencia.

## GitHub Pages bekapcsolása
1. Hozz létre egy új publikus tárolót (repository) a GitHubon (pl. `Auris-Cast-Dossier`).
2. Töltsd fel ezt a mappát a GitHubra.
3. A repóban menj a **Settings ➔ Pages** menüpontba.
4. A **Build and deployment** résznél a **Source** legyen `Deploy from a branch`.
5. A **Branch** beállításnál válaszd a `main` ágat és a `/ (root)` mappát, majd kattints a **Save** gombra.
6. 1-2 percen belül megkapod a publikus linket:
   `https://<felhasznaloneved>.github.io/<reponév>/`
